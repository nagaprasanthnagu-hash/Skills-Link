{% comment %} Booking status timeline — frontend-only, read-only. Usage: {% include 'components/booking_status_timeline.html' with status=booking.status %} Maps the EXISTING status strings (pending, accepted, in_progress, completed, cancelled) onto four visual steps. It reads `status` and nothing else, never posts or links anywhere, and does not alter any status value. pending -> step 1 "Requested" is current accepted -> step 1 done, step 2 "Accepted" is current in_progress -> steps 1-2 done, step 3 "In Progress" is current completed -> every step done cancelled -> all steps muted, plus a "cancelled" notice The booking model has no "On the Way" status, so that step is not drawn (drawing a step the data can never reach would be misleading). {% endcomment %}
